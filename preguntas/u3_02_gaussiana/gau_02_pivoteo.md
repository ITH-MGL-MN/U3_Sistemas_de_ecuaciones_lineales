titulo: Para qué sirve el pivoteo parcial
---

En el pivoteo parcial se elige como pivote el coeficiente de **mayor valor absoluto** de la columna.

**¿Qué se consigue con eso?**

- [x] Que todos los multiplicadores queden con $|m_{ik}| \le 1$, así el error de redondeo no se amplifica
- [ ] Que la matriz se vuelva simétrica
- [ ] Que el determinante cambie de signo
- [ ] Que el sistema tenga solución única aunque no la tuviera
