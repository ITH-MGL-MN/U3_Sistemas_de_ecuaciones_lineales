Un sistema $2\times2$ tiene $a_{11} = 0$ y determinante distinto de cero.

**¿Qué ocurre si se aplica eliminación gaussiana SIN pivoteo?**

- [x] El método se detiene porque el multiplicador $m_{21} = a_{21}/a_{11}$ no existe, aunque el sistema sí tenga solución única
- [ ] El método funciona igual y da la solución correcta
- [ ] El método da $x_1 = 0$ y sigue
- [ ] El determinante se vuelve cero y el sistema pierde su solución
